
A clean, responsive **Web App** built with **HTML, CSS, and JavaScript** that provides real-time exchange rates. It uses the **Fawaz Ahmed Currency API** to fetch live data and features a dynamic flag update system for a seamless user experience.



 Key Features
* Real-time Conversion:** Fetches the latest global exchange rates instantly.
*Dynamic Flags: Automatically updates country flags based on the selected currency.
* Responsive Design: Fully functional and aesthetically pleasing across all device sizes.
